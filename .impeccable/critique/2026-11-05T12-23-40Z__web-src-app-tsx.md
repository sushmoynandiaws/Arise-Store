#### Overall Impression
The catalog has a world-class typographic foundation and resilient offline caching, but it suffers from an identity conflict: it aspires to be an elevated artisan pavilion, but dresses itself like an ad-monetized deal aggregator. The most urgent improvements are restoring the mobile language toggle, eliminating redundant desktop search inputs, and bringing tactile craftsmanship (thumbnails, steppers, confirmation) into the Cart Drawer.

#### What's Working
1. **Resilient Offline Catalog State**: `CatalogRefreshNotice` (`App.tsx:121`) embodies source-owned integrity. When backend sync stalls, the UI keeps the last verified public catalog visible with a clear, calm status notice and retry trigger, pausing checkouts until integrity is restored.
2. **Dual-Script Typographic Craft**: Geometric Latin headings (`Urbanist`) and authentic Bengali body/headings (`Hind Siliguri`) coexist harmoniously. Dedicated CSS rules reset negative tracking for Bengali headings (`:lang(bn) :is(h1, h2, h3, h4) { letter-spacing: 0; line-height: 1.4; }`), preserving Indic vowel ligatures.
3. **Strict Touch Ergonomics & Dialog Management**: Interactive controls enforce 44px minimum bounding targets. Native `<dialog>` elements across drawers and modals isolate keyboard focus, respond to `Escape`, and lock background scroll cleanly.

#### Priority Issues

- **[P0] Mobile Language Switcher Disappears in Sticky Header**
  - **Why it matters**: In `styles.css:3306` (`@media (max-width: 640px)`), `.header-actions .lang-toggle-pill-group` is hidden with `display: none;`. Over 80% of Bangladeshi shoppers browse on mobile smartphones. Forcing them to open the hamburger drawer and scroll to the bottom just to switch to Bengali violates bilingual equality.
  - **Fix**: Render a compact 44px language toggle button (`বাং` / `EN`) in the mobile top action bar directly beside the Bag and Wishlist triggers.
  - **Suggested command**: `$impeccable adapt`

- **[P1] Cart Drawer Strips Visual Craft & Ergonomics (No Images, Raw Inputs, Accidental Cart Wipe)**
  - **Why it matters**: The Cart Drawer (`Commerce.tsx:384–486`) lacks product thumbnails, displays raw `<input type="number">` spinboxes (which summon the mobile soft keyboard and obscure the checkout CTA), and places an unconfirmed full-width "Empty bag" destructive button directly beneath Checkout.
  - **Fix**: (1) Add a 56×56 rounded product art thumbnail with fulfillment badge ("ডিজিটাল ডেলিভারি" / "কুরিয়ার পার্সেল") to each cart line; (2) Replace raw number inputs with tactile `[-]` `[qty]` `[+]` button steppers; (3) Move "Empty bag" to a quiet secondary text button requiring confirmation; (4) Add smooth slide-in cubic-bezier transition.
  - **Suggested command**: `$impeccable shape`

- **[P1] Dual Redundant Search Bars in Homepage Desktop Viewport**
  - **Why it matters**: Desktop viewports display `.header-center-search` in the sticky header and `.hero-search` in the hero banner (`App.tsx:1814`) simultaneously. This violates the Single Focus rule, confuses users over search scope, and consumes prime hero space that belongs to curated artisan discovery.
  - **Fix**: Remove `.hero-search` and `.hero-popular` from the hero banner. Rely on the prominent sticky header search for marketplace-wide queries, and dedicate the hero to brand positioning and curated discovery.
  - **Suggested command**: `$impeccable distill`

- **[P2] Hard Multi-Shop Cart Lockout Without Remediation**
  - **Why it matters**: When a user adds an item from a second seller, `Commerce.tsx:273` throws a rigid red alert: *"Complete or empty this bag first. Add products from one shop and fulfillment type together."* In a multi-vendor store, blocking cross-shop discovery without an automated path to save or split orders causes immediate drop-off.
  - **Fix**: Provide actionable resolution options in the notice: `[Checkout Current Bag]` or `[Save Current Bag & Start New One]`.
  - **Suggested command**: `$impeccable clarify`

- **[P2] Negative Letter-Spacing Bleed into Bengali Price Text**
  - **Why it matters**: In `styles.css:262`, `.price` enforces `letter-spacing: -.03em;`. In `ProductCard` (`App.tsx:1554`), the prefix string `{lang === "bn" ? "শুরু " : "From "}` renders inside `.price small`, inheriting negative tracking and distorting Bengali vowel ligatures ("শু", "রু").
  - **Fix**: Add `:lang(bn) .price, :lang(bn) .price small { letter-spacing: 0; }` in `styles.css`.
  - **Suggested command**: `$impeccable typeset`
